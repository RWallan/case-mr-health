# Reajuste do modelo servido na série estendida

Status: resolved
Type: task
Parent: #1
Blocked by: #28

## What to build

Para uma série, lê algoritmo e hiperparâmetros da versão servida, reajusta na série estendida, recalibra os intervalos e registra uma nova versão (hash, tags `origem=atualizacao`, `versao_anterior`, `hash_dados`, `desenvolvimento_fim` novo). Sem nova seleção, sem backtest e sem OOT. Segue a política do ADR 0011 para o alias `champion`.

## Acceptance criteria

- [x] Nova versão registrada com as tags de rastreabilidade
- [x] Mesmo algoritmo e hiperparâmetros da versão anterior
- [x] Falha numa série não troca a versão servida dela
- [x] Testes (Seam 2) com MLflow temporário
- [x] Fragmento towncrier `29.adicionado.md`

## Answer

`src/case_mr_health/reajuste.py` (`reajustar_serie`) lê algoritmo, hiperparâmetros (tag `hiperparametros`, em JSON), método de intervalo e seed da versão servida, reajusta na série completa de `db_path`, recalibra os intervalos pelo mesmo método (nativo ou empírico) e registra uma versão nova com as tags `origem=atualizacao`, `versao_anterior`, `hash_dados`, hash do artefato e `desenvolvimento_fim` igual ao fim da série nova (domingo, na semanal). Sem backtest, sem OOT. O `champion` passa para a versão nova, exceto quando a série tem versão fixada por configuração. Falha não troca a versão servida.

**Achado.** Os hiperparâmetros voltam do JSON com listas no lugar de tuplas (SARIMA); os previsores aceitam as listas (verificado).

**Números.** `tests/test_reajuste.py`: 11 testes passam. Suíte rápida: 541 passaram; evidência em `.ds-workflow/test-evidence/test-run-20261030T094959-1151433.json`.

**Limitações.** A versão reajustada não tem métrica fora da amostra. O reajuste repete o hiperparâmetro escolhido no #12 sem reavaliá-lo na série maior.
