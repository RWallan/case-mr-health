# Dashboard Svelte por SKU e granularidade com histórico, previsão e intervalos

Status: resolved
Type: task
Parent: #1
Blocked by: #14

## What to build

O primeiro caminho completo do frontend, em versão simples (decisão do usuário, 2026-10-30): uma única página em Svelte com Vite, sem SvelteKit, sem roteamento, sem biblioteca de estado e sem design system. O gestor escolhe um SKU e uma granularidade (diária ou semanal) e vê um gráfico com o histórico de vendas e a previsão, visualmente diferenciada, com os intervalos de 80% e 95% e o valor previsto. A tela diz que a previsão é da rede. Confiança e aviso de Insuficiente foram removidos no #27.

O cabeçalho da página tem um link para a UI do MLflow, que abre em outra aba. O endereço vem de configuração do frontend (`VITE_MLFLOW_URL`, padrão `http://localhost:5000`).

A spec não lista uma rota de histórico de vendas, mas o dashboard precisa dela (história 5). Este ticket a adiciona à API, servindo a série a partir dos dados persistidos, com a marcação de zero imputado.

## Acceptance criteria

- [x] Projeto Svelte com Vite, com instruções de execução; `npm run build` sem erros
- [x] Rota de histórico de vendas por SKU e granularidade, com teste (Seam 3) e Swagger
- [x] Seleção de SKU e granularidade, gráfico com histórico, previsão e intervalos
- [x] Link para a UI do MLflow no cabeçalho, com endereço configurável
- [x] Fragmento towncrier `22.adicionado.md`

## Answer

Entregue o dashboard em `frontend/`, com seleção de SKU e granularidade,
consulta do histórico de desenvolvimento e envio de predição à API. O gráfico
distingue histórico e previsão e mostra os intervalos por período. A interface
identifica que a previsão representa a rede e oferece link configurável para o
MLflow. O histórico semanal marca `imputado=false`; a diária preserva o campo
de imputação da base autorizada de desenvolvimento. Nenhum treino é iniciado.

Verificação: `npm run build` concluiu com sucesso em 2026-10-30. Os testes da
rota de série estão registrados em `.ds-workflow/test-evidence/`.
