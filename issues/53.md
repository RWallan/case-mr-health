# Instalação: grupo docs no uv sync e node_modules fora do Git

Status: resolved
Type: bug
Parent: #1

## What to build

Dois erros ao seguir o README num clone novo e rodar `uv run poe app`: `mkdocs` não encontrado (o grupo `docs` não vinha no `uv sync`) e `vite/dist/node/cli.js` ausente (`frontend/node_modules` estava versionado, mas o `.gitignore` tem `dist/`, então os `dist/` dos pacotes nunca foram commitados).

## Acceptance criteria

- [x] `uv sync` instala o grupo `docs` (`[tool.uv] default-groups`)
- [x] `frontend/node_modules` fora do Git e em `.gitignore`; README usa `npm ci`
- [x] Fragmento towncrier `53.correcoes.md`

## Answer

`default-groups = ["dev", "docs"]` faz o `uv sync` instalar o MkDocs; `uv.lock` não mudou. `node_modules` foi retirado do índice (`git rm --cached`, 1214 arquivos; a pasta local permanece) e o README passou a pedir `npm ci`. Quem já tem um clone precisa rodar `rm -rf frontend/node_modules && (cd frontend && npm ci)`. Limitação: o `npm ci` num clone limpo não foi executado aqui; a causa do `vite/dist` foi confirmada por `git check-ignore`. A porta 5000 ocupada relatada na mesma execução é do ambiente do usuário, não do repositório.
