# Parar o app e liberar as portas

Status: resolved
Type: task
Parent: #1

## What to build

O `poe app` deixa processos órfãos (uvicorn, workers do MLflow) ao ser interrompido, e a próxima execução falha com `[Errno 98] Address already in use`. Criar uma forma imediata de liberar as portas do app e usá-la antes de subir.

## Acceptance criteria

- [x] `uv run poe parar` encerra quem escuta em 8000, 5000, 5173 e 8001
- [x] `uv run poe app` libera as portas antes de subir
- [x] README e guia de operação atualizados
- [x] Fragmento towncrier `54.adicionado.md`

## Answer

`scripts/parar_app.py` usa `fuser -k -KILL <porta>/tcp` e loga com loguru; `app` virou a sequência `parar` + parallel. Verificado com um servidor de teste na 8000, que foi encerrado. Limitações: depende de `fuser` (Linux/WSL), usa SIGKILL sem encerramento gracioso e mata qualquer processo nessas portas, inclusive de outro programa; `poe app` completo e as demais portas não foram executados aqui.
