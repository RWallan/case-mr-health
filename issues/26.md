## What to build

O sistema integrado roda do zero, das planilhas brutas ao dashboard: preparar dados, treinar, promover, subir a API e abrir o dashboard. Testes de ponta a ponta com Playwright cobrem os fluxos principais do gestor contra o sistema integrado. O README documenta a execução, a configuração (incluindo como trocar o MLflow para remoto só por configuração) e as limitações conhecidas (histórico curto, venda como proxy da demanda, único worker por causa do DuckDB).

Fecha a Fase 8, com revisão final apresentada ao usuário.
