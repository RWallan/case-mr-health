## What to build

O README documenta como o sistema roda do zero, das planilhas brutas ao dashboard: preparar dados, treinar, promover, subir a API, subir a UI do MLflow e abrir o dashboard. Ele documenta também a configuração (incluindo como trocar o MLflow para remoto só por configuração, e o endereço da UI do MLflow usado pelo link do dashboard) e as limitações conhecidas (histórico curto, venda como proxy da demanda, único worker por causa do DuckDB).

Sem Playwright (decisão do usuário, 2026-10-30). A verificação é uma passada de fumaça com o `champion` já promovido, sem retreinar: subir a API e a UI do MLflow, chamar a rota de predição, gerar o build do dashboard e abrir a página. A verificação visual da tela fica para a revisão do usuário.
