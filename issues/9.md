# Confiança derivada do MASE com o status Insuficiente

Status: ready-for-agent
Type: task
Parent: #1
Blocked by: #7

## What to build

Cada modelo treinado recebe uma confiança, associada à sua versão no Registry, para que o gestor saiba quanto peso dar a cada número.

- Faixas iniciais de MASE, configuráveis: até 0,50 é Ótima; de 0,50 a 0,75, Boa; de 0,75 a 1,00, Média; acima de 1,00, Ruim.
- O status é Insuficiente quando não há evidência, por exemplo quando a escala do baseline do MASE é zero. Insuficiente não é Ruim (`GLOSSARY.md`).
- Há uma alternativa documentada para quando o MASE é instável, em vez de forçar uma classificação.
- A aplicabilidade das faixas é validada nos dados do backtest. Se elas não discriminarem nada nessas séries, isso é reportado ao usuário com uma proposta.

## Acceptance criteria

- [ ] Confiança calculada no backtest e gravada como metadado da versão do modelo
- [ ] Testes: fronteiras de cada faixa, MASE com escala zero resultando em Insuficiente
- [ ] Alternativa para MASE instável documentada
- [ ] Validação das faixas nos dados apresentada ao usuário
