# Recomendação determinística na API

Status: resolved
Type: task
Parent: #1
Blocked by: #14, #18

## What to build

O gestor consulta pela API a recomendação de cada SKU, calculada de forma determinística pela regra aprovada no #18, a partir do modelo semanal servido. A resposta traz o resultado (aumento significativo, redução significativa, estável ou Insuficiente), a variação percentual, o limite histórico (Q3) que a justifica, as médias comparadas, a confiança do modelo e o aviso de baixa confiabilidade estatística.

O texto fala em "pressão sobre o estoque" e nunca afirma ruptura. A decisão é só da regra; nenhum LLM participa.

## Acceptance criteria

- [x] Rota de recomendações
- [x] Testes (Seam 3) com séries construídas para cada caso do #18: aumento, redução, estável e Insuficiente
- [x] Aviso de baixa confiabilidade presente em toda resposta
- [x] Swagger documentado
- [x] Fragmento towncrier `19.adicionado.md`; testes rápidos verdes (a suíte lenta não roda após o #12, ver plano de paralelização)

## Answer

`GET /recomendacoes/{sku}` implementa a especificação aprovada no #18. A regra pura está em `src/case_mr_health/recomendacao.py` (`recomendar`, `variacoes_historicas`); o serviço em `api/servicos/recomendacao.py` lê as semanas completas do banco de **desenvolvimento** até a última semana do treino, pede ao modelo semanal (`champion` ou fixado) os passos 1 e 2 e grava as duas semanas previstas no histórico, como as predições.

**Números.** `tests/test_api_recomendacao.py`: 31 testes passam (21 s), com os 5 casos do #18 reproduzidos (variações +0,4706, −0,3333, +0,0588, base zero e +0,4783; Q3 0,3069 e 0,2053), mais limite exato (`|variação| = Q3` é `estavel`) e variação 0. Suíte rápida completa: 472 passaram, 48 lentos excluídos; evidência em `.ds-workflow/test-evidence/test-run-20261030T085521-956408.json`. Lint verde.

**Interpretação a confirmar.** A spec diz "SKU sem modelo semanal → 404". Implementei 404 só para SKU inexistente e **503** (`modelo_indisponivel`) para SKU válido sem modelo servível, igual ao #14, por ser indisponibilidade e não ausência do recurso. Se a intenção era 404, é uma troca de uma linha.

**Limitações.** A recomendação vale para a origem fixa do treino (2021), não para a semana corrente, pelo mesmo motivo do #14. Com 12 semanas há no máximo 7 janelas, por isso o aviso fixo. A exportação XLSX (#16) segue sem coluna de recomendação: o histórico guarda previsões, não o resultado da regra. A confiança não participa (D-020).
