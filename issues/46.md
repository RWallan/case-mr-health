# Changelog legível dentro do app

Status: resolved
Type: task
Parent: #1
Blocked by: #42

## What to build

O link "Changelog" do cabeçalho (`LinksApi.svelte`) abre `GET /changelog`, que devolve JSON. Substituir por visão `#/changelog` no próprio app que consome `GET /changelog` e mostra versões, data, tipos e itens; issues como texto simples (`#NN`), pois não há servidor para `issues/NN.md`. A fonte continua sendo `CHANGELOG.md` (nome real do arquivo; `changelog_path`), sem cópia nem biblioteca de Markdown; versões novas aparecem sozinhas. Estados: carregando, vazio (200 com `versoes` vazia) e erro.

## Acceptance criteria

- [ ] O link abre a visão renderizada, não JSON
- [ ] Nova versão no `CHANGELOG.md` aparece sem alterar o frontend
- [ ] Estados vazio e de erro tratados
- [ ] `uv run poe lint` e `uv run poe test-rapido` verdes (no que tocar o backend)
- [ ] Fragmento towncrier `46.<tipo>.md`; registro em `docs/relatorio/registro-onda6.md`; seção `## Answer` nesta issue

## Answer

Entregue em 2026-10-30 (branch `46-changelog_no_app`).

- O link "Changelog" do cabeçalho (`LinksApi.svelte`) agora aponta para `#/changelog`, visão dentro do app (`Changelog.svelte`), que consome `GET /changelog` e mostra, por versão, número, data (dd/mm/aaaa), tipo e itens; issues como texto simples (`#NN`). Sem roteador externo: `App.svelte` lê `location.hash` (`rotaDoHash`, em `frontend/src/changelog.js`) e troca o `<main>` pela visão; `onhashchange` atualiza a rota. A visão tem link "Voltar à previsão" (`#/`).
- Versões novas aparecem sozinhas: a ordem e o conteúdo vêm do backend (`CHANGELOG.md`, `changelog_path`); o frontend não tem lista de versões nem de tipos.
- Estados: carregando, vazio (200 com `versoes` vazia: "Nenhuma versão publicada ainda.") e erro (resposta não-2xx ou falha de rede, com botão "Tentar de novo").
- Lógica pura (rota, data, issues, preparo das versões) em `changelog.js`, com 5 testes em `changelog.test.js` (`uv run poe test-frontend`: todos passam). Sem mudança de backend; `test-rapido` não foi necessário. `uv run poe lint` e `npm run build` passam; nenhum hexadecimal em `frontend/src`.

Limitações: sem teste do componente em navegador; o hash não restaura a rota ao voltar do histórico além do `onhashchange`; trocar de rota desmonta o formulário de previsão (o estado de `App.svelte` é preservado, o de componentes filhos não). O build neste worktree exigiu copiar as pastas `dist` ignoradas de `frontend/node_modules` do checkout principal (não versionadas).

Roteiro visual (`uv run poe app`): clicar em "Changelog" e ver a lista renderizada; conferir "Voltar à previsão"; parar a API e recarregar `#/changelog` para ver o erro; apontar `changelog_path` para arquivo inexistente para ver o estado vazio.
