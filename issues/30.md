# Rota de atualização de dados com reajuste em segundo plano

Status: resolved
Type: task
Parent: #1
Blocked by: #28, #29

## What to build

`POST /dados/pedidos` (dois XLSX) responde 202 com um identificador; `GET /dados/atualizacoes/{id}` informa estado, séries reajustadas e erros. Uma atualização por vez. Ao concluir, a API passa a servir as versões novas sem reiniciar. Swagger documentado, com o aviso de que versões reajustadas não têm métrica fora da amostra.

## Acceptance criteria

- [x] Rotas de envio e de acompanhamento
- [x] Segunda atualização durante uma em andamento é recusada (409)
- [x] API serve a versão nova depois da conclusão, sem reinício
- [x] Testes (Seam 3) com modelos pré-registrados e MLflow temporário
- [x] Fragmento towncrier `30.adicionado.md`

## Answer

`POST /dados/pedidos` (dois XLSX) valida na requisição (422 com `PLANILHA linha N`, 409 para par já aplicado ou atualização em andamento) e responde 202; o reajuste das 8 séries roda numa thread, uma atualização por vez. Cada série reajustada recarrega a versão nova no catálogo sem reiniciar. `GET /dados/atualizacoes/{id}` informa estado (`em_andamento`, `concluida`, `concluida_com_erros`, `falhou`) e o resultado por série (`reajustada`, `ignorada`, `falhou`). Uma série com falha não derruba as outras nem troca a versão servida dela. As respostas de predição, recomendação e `GET /modelos` trazem a origem do modelo (`treino` ou `atualizacao`); o gráfico (`GET /series`) e a recomendação passam a ler a base completa. Comando `case-mr-health reajustar` para recuperação.

**Achado.** O `GET /modelos` (#16) nunca mostrava o `champion`: a busca de versões do MLflow não devolve aliases e o teste usava dublê. Corrigido lendo os aliases do modelo registrado.

**Números.** `tests/test_api_atualizacao.py`: 16 testes passam. Suíte rápida: 541 passaram; evidência em `.ds-workflow/test-evidence/test-run-20261030T094959-1151433.json`.

**Limitações.** O estado das atualizações vive na memória: reiniciar a API perde o histórico delas (a base e as versões ficam). O reajuste compete por CPU com a API (thread, um único worker). Versões reajustadas não têm métrica fora da amostra.
