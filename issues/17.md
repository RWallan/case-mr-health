# Changelog estruturado na API

Status: resolved
Type: task
Parent: #1
Blocked by: #14

## What to build

O administrador consulta pela API o changelog do projeto em formato estruturado (versões, datas e mudanças por tipo), extraído do `CHANGELOG.md` gerado pelo towncrier.

## Acceptance criteria

- [x] Rota de changelog estruturado
- [x] Testes (Seam 3) com um CHANGELOG sintético: versões, datas e tipos de mudança extraídos corretamente; changelog vazio ou ausente tratado
- [x] Swagger documentado
- [x] Fragmento towncrier `17.adicionado.md`
- [ ] Suíte rápida da integração verde (a executar após empilhar os tickets; treino real não deve ser repetido)

## Answer

**Aceita para integração pelo usuário em 2026-10-30.**

`GET /changelog` devolve as versões do `CHANGELOG.md` na ordem do arquivo, cada uma com `versao`, `data` e `secoes`; cada seção tem `tipo` e `itens`, e cada item tem `texto` (sem os links finais) e `issues` (IDs). O caminho vem de `Settings.changelog_path`, por `Depends(obter_settings)`. Registro completo em `docs/relatorio/fase5/17.md`.

- **Decisões do agente, a revisar:** `tipo` usa o título do towncrier (`Correções`, não `correcoes`). Os tipos ficam fixos em `TipoMudanca`, sem ler o `pyproject.toml` em tempo de execução, e um teste confere que os dois coincidem. Seção desconhecida é ignorada com seus itens.
- **Falhas toleradas:** arquivo ausente, vazio ou ilegível responde 200 com `versoes: []` e aviso no log. Linha fora do formato é ignorada com aviso, e o que vem abaixo de um título inválido não vai para a versão anterior.
- **Números:** 16 testes em `tests/test_api_changelog.py` passaram; `uv run poe lint` limpo. No `CHANGELOG.md` real, 2 versões, 18 itens e 12 com link, iguais à contagem por `grep`, sem nenhum aviso.

**Limitações.** `uv run poe test` não foi executado, por proibição do usuário (suíte de mais de 26 min): só o arquivo de testes do ticket e o lint. A rota ainda não está em `criar_app` (#14); falta uma linha de `include_router` na integração. `changelog_path` é relativo ao diretório de execução: fora da raiz do projeto, ou numa imagem sem o arquivo, a rota responde vazia em vez de falhar, e o sinal fica só no log. Parágrafos de um mesmo fragmento são unidos num texto só.
