# Labels de triage

As skills falam em termos de cinco papéis canônicos de triage. Este arquivo mapeia esses papéis para os valores usados neste repositório. Como as issues são locais, o valor é registrado na linha `Status:` de cada `issues/<ID>.md`.

| Label em mattpocock/skills | Valor no nosso tracker | Significado                                   |
| -------------------------- | ---------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`         | Mantenedor precisa avaliar a issue            |
| `needs-info`               | `needs-info`           | Aguardando mais informações de quem reportou  |
| `ready-for-agent`          | `ready-for-agent`      | Totalmente especificada, pronta para um agente |
| `ready-for-human`          | `ready-for-human`      | Requer implementação humana                   |
| `wontfix`                  | `wontfix`              | Não será feita                                |

Quando uma skill mencionar um papel (ex.: "aplique a label de pronta para agente"), use o valor correspondente desta tabela.

Edite a coluna "Valor no nosso tracker" para refletir o vocabulário que você realmente usa.
