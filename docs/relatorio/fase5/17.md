# Bloco de registro do ticket #17 — Changelog estruturado na API

Branch `17-changelog_api`, a partir de `0dfb3d7`. Sem commit: aguarda revisão e integração. Fase 5, conforme `issues/1.md` ("contratos, serviço de predição, XLSX, histórico, changelog e Swagger"). As decisões abaixo são do agente e estão **propostas** até a aprovação do usuário.

**Entregue:**
- `src/case_mr_health/api/rotas/changelog.py`: `router`, `GET /changelog` e `obter_settings`.
- `src/case_mr_health/api/schemas/changelog.py`: `TipoMudanca`, `Item`, `Secao`, `Versao` e `Changelog`, com descrições e exemplo no Swagger.
- `src/case_mr_health/api/servicos/changelog.py`: parser `ler_changelog(caminho: Path) -> Changelog`.
- `__init__.py` vazios em `api/`, `api/rotas/`, `api/schemas/` e `api/servicos/`.
- `src/case_mr_health/config.py`: campo `changelog_path = Path('CHANGELOG.md')`.
- `tests/test_api_changelog.py` (16 testes, Seam 3, `FastAPI()` mínimo com `include_router`, sem `app.py`), `changelogs/17.adicionado.md`.

**Regras e decisões de implementação (do agente, propostas):**
1. **`tipo` é o título do towncrier** (`Adicionado`, `Correções`, ...), não o nome do diretório. Um campo só, que já serve para exibição. Descartado: dois campos, `tipo` (`correcoes`) e `titulo`; o #25 só precisa de um link para o changelog.
2. **Tipos fixos em `TipoMudanca`.** O `pyproject.toml` pode não existir onde o serviço roda, então o parser não o lê. `test_tipos_acompanham_o_towncrier` falha se os dois divergirem. Um tipo novo no towncrier exige mudar o enum.
3. **Título fora do formato interrompe a associação.** Depois de um `# ...` inválido, seções e itens não entram na versão anterior; depois de um `## ...` desconhecido, os itens também não. Cada linha descartada gera aviso. Versão sem data ou com data impossível (`2026-13-45`) é descartada, pois `data` é obrigatória no contrato.
4. **Links.** `issues` guarda os IDs de todos os links `[#N](issues/N.md)` do item, na ordem e sem repetição, inclusive os do meio do texto. `texto` perde apenas o grupo final entre parênteses gerado pelo towncrier; um link no meio do texto permanece. Referência solta (`#7` sem link) não conta.
5. **Arquivo ilegível** (erro de sistema de arquivos ou bytes fora de UTF-8) segue o tratamento do ausente: 200 com `versoes: []` e aviso. A especificação citava ausente e vazio; a extensão vem da regra de não responder 500.

**Fatos verificados:**
- Saída real do towncrier 26.9 (`build --draft` em diretório temporário com fragmentos sintéticos): issues do mesmo texto saem juntas em `- Texto. ([#1](issues/1.md), [#2](issues/2.md))`; fragmento de várias linhas sai com continuação indentada em 2 espaços, com linha em branco entre parágrafos. O parser cobre os dois casos.
- `CHANGELOG.md` real, lido com `ler_changelog`: 0.3.0 (2026-10-30; Adicionado e Alterado; 7 itens, 6 com link) e 0.2.0 (2026-10-30; Adicionado e Interno; 11 itens, 6 com link). Total de 18 itens e 12 com link, igual a `grep -c '^- '` e `grep -c '^- .*issues/'`. Nenhum aviso.
- `uv run pytest tests/test_api_changelog.py`: 16 passaram. `uv run poe lint`: "All checks passed!".

**Desvios do plano:** o critério "`uv run poe test` verde" da issue não foi executado, por proibição do usuário (a suíte passa de 26 min). Valem apenas o arquivo de testes do ticket e o lint. A issue declara bloqueio pelo #14, mas o ticket correu em paralelo; a dependência se reduziu ao layout congelado de `api/`.

**Limitações:**
- A rota ainda não está em `criar_app`; falta `app.include_router(router)` na integração.
- Se o #14 criar uma dependência de `Settings` própria, `obter_settings` de `rotas/changelog.py` deve ser trocada por ela (e os testes ajustados).
- `changelog_path` é relativo ao diretório de execução. Fora da raiz, ou numa imagem sem o `CHANGELOG.md`, a rota responde vazia, e o único sinal é o aviso no log.
- O arquivo é relido a cada requisição, sem cache; é pequeno e a rota é de consulta eventual.
- Parágrafos de um mesmo fragmento são unidos com espaço em `texto`.

**Reprodução:**
```bash
uv run pytest tests/test_api_changelog.py
uv run poe lint
```
